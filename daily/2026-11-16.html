Pytest fixture：生命周期与共享

复习yield、scope、conftest.py、tmp_path，结合真实电脑运行练习。

返回学习中心

先理解执行顺序

pytest发现测试函数 → 解析参数report → 执行fixture的准备代码 → yield交出数据 → 执行测试断言 → 执行yield后的清理代码。

import pytest

@pytest.fixture
def report():
    print("准备")
    yield {"loss": 0}
    print("清理")

def test_loss(report):
    print("测试")
    assert report["loss"] == 0

运行：python -m pytest -s -v test_fixture.py。-s显示print，-v显示详细用例信息。PASSED表示断言通过，不代表清理没有执行。

电脑独立实操

① 独立写一个yield fixture，并运行pytest -s -v，解释准备/测试/清理的顺序。

② 把共享fixture放进conftest.py，让两个测试文件都能使用；使用tmp_path写入并读取report.json。提交代码和实际运行输出。
