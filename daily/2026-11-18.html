原理与数据流

测试数据每行 → pytest注入loss、expected → 调用get_status → assert比较 → 每组独立汇总。

import pytest
from report_utils import get_status

@pytest.mark.parametrize("loss, expected", [
    (0, "PASS"),
    (2, "FAIL"),
    (-1, "ERROR"),
])
def test_status(loss, expected):
    assert get_status(loss) == expected

这是结构示例，不等于独立编写。pytest.raises检查是否真正抛出异常；当前get_status返回ERROR，不应把它误认为抛出异常。
