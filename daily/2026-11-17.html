先理解数据流

参数数据行 → pytest注入loss和expected → 调用get_status → assert比较 → 每行单独记录PASS/FAIL。 参数化不改变被测函数，也不自动决定预期。

import pytest
from report_utils import get_status

@pytest.mark.parametrize("loss, expected", [
    ("0", "ERROR"),
    (False, "ERROR"),
])
def test_invalid_loss(loss, expected):
    assert get_status(loss) == expected
逐步执行说明（点击展开）

① pytest收集测试函数。② 读取第一行数据，把字符串"0"注入loss，把"ERROR"注入expected。③ 调用get_status("0")。④ 比较实际返回值与expected。⑤ 再执行下一行False，形成另一条独立结果。

fixture与数据准备

fixture是pytest按测试函数参数名注入的资源；yield前准备、后清理；tmp_path提供隔离目录；conftest.py可共享fixture定义。测试返回ERROR与抛出ValueError是两种不同契约，不能混用assert和pytest.raises。
